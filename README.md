# Visual Defect Detector

Простой скрипт для первичной проверки изображений на наличие дефектов (по преобладанию красного цвета).

## Требования
* Go 1.18 или выше

## Запуск

1. Склонируйте репозиторий и перейдите в папку проекта.
2. Для проверки заведомо корректного изображения (`ok.png`):
   ```bash
   go run main.go ok.png
